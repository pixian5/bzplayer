## 一、要解决的问题

根因分析已确认：该文件是 **MP3 封装在 MP4 容器内**（音频 fourcc 标为 `mp4a`，真实编码是 mp3），AVFoundation 无法识别/解码这条音轨，于是信息面板「音频轨道：0」，播放无声音；VLC/libavcodec 不挑容器，正常出声。

但播放器的后端路由把 MP3 列入了"原生安全音频编码"白名单（`nativeSafeAudioCodecs` 含 `"mp3"`、`nativeSafeAudioSubtypes` 含 `".mp3"` 与 `"mp4a"`），**只看编码名、不结合容器判断**，导致 MP3-in-MP4 被误判为 AVPlayer 可播，默认走原生后端，于是"找不到音轨"。文件信息面板那句"AVFoundation 未识别音轨会自动切 VLC"因此对该文件并未真正生效。

## 二、改动（文件 `macos/BZPlayer/Sources/BZPlayerApp/PlayerViewModel.swift`）

### 1. 新增 MP4 系列容器判断与不安全音频集合（约 2367–2377 行）

```swift
/// MP4 系列容器（ISO BMFF / M4V / 3GP 等）下，AVFoundation 因封装方式不支持、必须走 VLC 的音频编码。
private let mp4FamilyUnsafeAudioCodecs: Set<String> = ["mp3"]
private let mp4FamilyUnsafeAudioSubtypes: Set<String> = [".mp3", "mp3 "]

private func isMP4FamilyContainer(_ ext: String) -> Bool {
    let mp4Family: Set<String> = ["mp4", "m4v", "m4a", "3gp", "3g2", "f4v"]
    return mp4Family.contains(ext.lowercased())
}
```

### 2. `shouldPreferVLC(ffprobeInfo:)` 增加容器参数并加判（约 2379、2406–2410 行）

```swift
private func shouldPreferVLC(ffprobeInfo: FFprobeInfo, containerExtension: String) -> Bool {
    // ... 既有视频/音频白名单判断保持不变 ...
    if ffprobeInfo.audioStreams.contains(where: { !nativeSafeAudioCodecs.contains($0.codecName) }) {
        return true
    }
    // 新增：MP4 系列容器中的 MP3 音轨，强制走 VLC
    if isMP4FamilyContainer(containerExtension),
       ffprobeInfo.audioStreams.contains(where: { mp4FamilyUnsafeAudioCodecs.contains($0.codecName) }) {
        return true
    }
    return false
}
```

### 3. `shouldPreferVLC(asset:)` 末尾加同样逻辑的兜底（约 2447–2457 行）

覆盖 ffprobe 不可用、但 AVAsset 能识别到 `.mp3` 子类型的情况。`mp4a` 子类型无法区分内部是 AAC 还是 MP3，所以仍依赖上面的 ffprobe 路径判断。

```swift
if isMP4FamilyContainer(asset.url.pathExtension) {
    for track in audioTracks {
        guard let formatDescriptions = try? await track.load(.formatDescriptions) else { continue }
        for formatDescription in formatDescriptions {
            let subtype = codecSubtypeString(from: formatDescription)
            if mp4FamilyUnsafeAudioSubtypes.contains(subtype) { return true }
        }
    }
}
```

### 4. `chooseBackend` 调用处传入容器扩展名（约 2318 行）

```swift
if shouldPreferVLC(ffprobeInfo: ffprobeInfo, containerExtension: url.pathExtension) {
    return .vlc
}
```

## 三、为什么这样改（设计取舍）

- **不扩大白名单含义**：`nativeSafeAudioCodecs` 仍保留 `"mp3"`，因为纯 `.mp3`、QuickTime 的 `.mp3` 采样描述在 AVFoundation 下是可播的；只在"MP4 系列容器 + mp3"这一具体组合上强制 VLC，避免误伤正常文件。
- **双路径兜底**：优先用 ffprobe 的精确 codec 名判断；AVAsset 路径只作为 ffprobe 缺失时的补充，且仅对能直接识别为 `.mp3` 子类型的情形生效，不信任 `mp4a`（它既可能包 AAC 也可能包 MP3）。
- **无回归**：普通 AAC/AC3/ALAC 等封装在 mp4 的文件不在不安全集合内，仍走 AVPlayer，行为与修复前一致。
