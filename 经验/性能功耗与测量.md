# 性能功耗与测量

## 1. audio-only（最小化到 Dock 仅播放音频）是实验功能

【结论】"最小化到 Dock 时仅播放音频"**默认关闭**，属实验功能。开启后在最小化时：禁用 AVPlayer 视频轨，或让 VLC 以 `:no-video` 重新加载；恢复窗口时重新加载视频。
【避坑要点】该功能**可能产生短暂切换**；节能效果**必须在目标机器实测**，不能仅凭配置推断。
【依据/来源】`readme.md` 重大说明。

## 2. A/B 测量脚本用法

【结论】`scripts/measure_audio_only.sh` 依次测 `normal` 与 `audio-only` 两组，记录播放器 CPU、`top`、`pmset`、`ioreg` 与可用时的 `powermetrics` 原始数据。
【依据/来源】`scripts/measure_audio_only.sh`。

```bash
bash scripts/measure_audio_only.sh "/path/to/media.mp4" \
  --runs 3 --warmup 120 --duration 600
```

| 选项 | 含义 | 默认 |
|---|---|---|
| `--runs` | 每种模式重复次数 | 1 |
| `--warmup` | 播放就绪后的稳定时间（秒） | 15 |
| `--duration` | 标记后的采样时长（秒） | 60 |
| `--output` | 输出目录 | `artifacts/audio-only-benchmark-<时间>` |
| `--app` | `.app` 路径 | `/Applications/BZPlayer.app` |

## 3. 脚本前提（缺一不可）

【结论】
- 目标 `.app` 必须已安装且可执行：`/Applications/BZPlayer.app/Contents/MacOS/BZPlayer`。
- 应用接受 `--benchmark-media/--benchmark-mode/--benchmark-duration/--benchmark-warmup/--benchmark-speed/--benchmark-start-file` 参数（benchmark 模式）。
- 应用在"媒体从头播放、倍速固定 `1x`、状态稳定"后写入测量开始标记，再自动退出。
- `powermetrics` **需要免密 sudo**（`sudo -n true` 通过才采集）；否则记录 `unavailable`。
- 环境记录依赖 `/opt/homebrew/bin/ffprobe`（缺失时该段留空，不阻断）。
【避坑要点】脚本会 `pkill BZPlayer` 并重新启动，测量期间不要手动操作该应用。
【依据/来源】`scripts/measure_audio_only.sh` L101-136、L203-210。

## 4. 测量纪律（不可违背）

【结论】两组测试必须保持**相同的电源、屏幕亮度、外接显示器、网络和后台负载**；建议每种模式 **≥3 次**。
【避坑要点】**短媒体或过短时长只能验证流程，不能据此宣称节能**；结果只提供原始证据，脚本不自动下结论。
【依据/来源】`scripts/measure_audio_only.sh` L14-19、L287-299 与 `readme.md`。

## 5. 输出产物

每个 run 目录含：`environment.txt`、`process-and-battery.log`、`top.txt`、`powermetrics.txt`、`measurement-window.txt`、`battery-before/after.txt`、`started/finished.txt`；总目录另有 `README.txt`。
