# 经验索引（BZPlayer）

本目录把 `docs/` 的文档**分类提炼成简洁、已核对的避坑经验**，用于快速了解项目、避免重复踩坑。

> ⚠️ `docs/` 里的文档**不一定正确**（多为当时的分析/记录快照，行号、规模、结论可能已随代码演进过时）。
> 需要可靠结论时，**以本目录经验为准**，或回到源码 / 实测重新复核。

## 每条经验的写法

- 每条经验按 【结论】【避坑要点】【依据/来源】 给出。
- 不确定、未独立验证的内容单独放「存疑/未验证」一节，**不当作事实**。
- 行号与版本号会随代码变化；引用时请以当前源码复核。

## 建议阅读顺序

1. 先读「项目现状与待办要点」了解整体。
2. 改播放逻辑前读「播放后端与编解码兼容」。
3. 碰内核读「VLC内核维护」；碰发布读「构建发布与版本号」。
